# Alpinestars Portfolio Project

## Publish
1. Create `projects/alpinestars/` inside your `haodong191.github.io` repository.
2. Upload `index.html`, `style.css`, `script.js`, and `products.json`.
3. Commit the changes.
4. Open `https://haodong191.github.io/projects/alpinestars/`.

## Add real product images
Each product in `products.json` has an `image` field. Paste the full Shopify/CDN image URL into that field and the product card will automatically switch from the placeholder to the actual image.

## Add products
Duplicate any product object in `products.json` and update its title, category, price, compareAt, status, badge, URL, and image. No HTML changes are required.
